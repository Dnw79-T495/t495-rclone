# T495-rclone

## Personal Google Drive Integration

T495-rclone is a personal desktop integration that uses the open-source rclone application to access Google Drive from a Lenovo ThinkPad T495 running EndeavourOS Linux.

### Purpose

This integration allows the device owner to:

- Browse Google Drive files through the Dolphin file manager.
- Access Google Drive files through the Linux terminal.
- Download, upload, and manage personal files when authorized.
- Mount Google Drive as a local filesystem using rclone.

### How It Works

T495-rclone uses Google's OAuth 2.0 authentication system to authorize access to the owner's Google Drive account.

Google Drive content is accessed directly through rclone on the owner's computer. This project does not operate a separate cloud file-processing server.

### Availability

This project is intended for personal use by its owner and is not offered as a public file-storage service.
