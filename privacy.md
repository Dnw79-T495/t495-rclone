# Privacy Policy — T495-rclone

**Last updated:** October 26, 2026

## Overview

T495-rclone is a personal integration that uses the open-source rclone application to access Google Drive from a Linux computer.

This integration is intended for use by the application owner and is not offered as a public service.

## Information Accessed

With the owner's authorization, rclone may access Google Drive information, including:

- File and folder names and metadata.
- File contents.
- Files and folders needed for authorized uploads, downloads, modifications, and deletions.

The application requests Google Drive permissions to support these functions.

## How Information Is Used

Google Drive information is accessed to provide filesystem functionality through rclone, including browsing, transferring, opening, and managing files.

Google Drive data is not used for advertising, marketing, or profiling.

## Storage and Security

OAuth credentials are stored locally in the rclone configuration on the owner's computer.

Google Drive files are accessed through Google's API. Depending on rclone configuration, file data may be temporarily cached or stored locally when explicitly downloaded.

This project does not operate a separate server that collects or stores Google Drive file contents.

## Information Sharing

The project does not sell Google Drive information or intentionally share it with advertisers or third parties.

Google Drive information is processed by Google and rclone as necessary for the authorized integration.

## Data Retention and Deletion

Locally downloaded files remain on the owner's device until removed.

The owner can revoke Google Drive access through their Google Account security settings and remove locally stored rclone credentials.

## Contact

For privacy questions, contact the application owner using the support contact associated with the T495-rclone OAuth application.

## Changes

This policy may be updated if the application's functionality or data-handling practices change.
